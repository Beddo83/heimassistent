Datenschutzerklärung

Stand: November 2026

Betreiber

Diese Anwendung wird von einer Privatperson in Deutschland betrieben, ausschließlich zu privaten Zwecken und ohne Gewinnerzielungsabsicht. Kontakt: heimassistent@gmx.de

Welche Daten verarbeitet werden

Die Anwendung greift ausschließlich auf den Google-Kalender des Betreibers zu, und zwar mit der Berechtigung calendar.events. Damit kann sie Termine dieses einen Kalenders lesen, anlegen, ändern und löschen. Andere Google-Dienste werden nicht angesprochen und keine weiteren Daten aus dem Google-Konto abgerufen.

Wo die Daten liegen

  • Die Zugangsschlüssel liegen in einer Datei auf dem privaten Rechner des Betreibers.
  • Termindaten werden nur für die Dauer einer Anfrage verarbeitet und nicht dauerhaft gespeichert.
  • Es gibt keinen Server im Internet, auf dem Daten dieser Anwendung lägen.

Weitergabe an Dritte

Keine. Die Daten werden nicht verkauft, nicht vermietet, nicht zu Werbezwecken ausgewertet und an niemanden weitergegeben.

Andere Nutzer

Es gibt keine. Die Anwendung wird von einer einzigen Person benutzt, nämlich dem Betreiber selbst. Eine Nutzung durch Dritte ist technisch nicht vorgesehen.

Google-Nutzungsbedingungen

Die Verwendung von Informationen, die über Google-APIs empfangen werden, erfolgt im Einklang mit der Google API Services User Data Policy, einschließlich der dort genannten Limited-Use-Anforderungen.

Zugriff widerrufen

Der Betreiber kann den Zugriff jederzeit in den Sicherheitseinstellungen seines eigenen Google-Kontos unter „Apps mit Zugriff auf Ihr Konto" entziehen. Der Zugriff endet damit sofort.

Diese Internetseite

Diese Seite besteht aus festen Textseiten. Sie setzt keine Cookies, bindet keine fremden Inhalte ein und wertet keine Besucherdaten aus. Sie wird bei GitHub Pages gehostet; beim Abruf fallen dort technisch bedingt Verbindungsdaten an, auf die der Betreiber keinen Zugriff hat.

Änderungen

Ändert sich der Umfang der Datenverarbeitung, wird diese Erklärung angepasst.
